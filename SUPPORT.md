# Support

This is an independent, community-maintained n8n integration.

## Get help

1. Review [installation and usage](README.md), [known limitations](docs/ARCHITECTURE.md),
   and [local development](DEV_SETUP.md).
2. Confirm the package version and n8n runtime you are using.
3. Search [existing issues](https://github.com/redoracle/n8n-nodes-the-bluesky/issues).
4. Open a **bug report** or **feature request** with the corresponding template.

Please provide package, n8n and Node.js versions, the minimal steps to
reproduce, expected vs. actual behavior and **sanitized** error logs.

Do not post app passwords, session tokens, private messages, credentials or
personal data. For vulnerabilities use [private security reporting](SECURITY.md)
rather than public issues.

Support is best-effort; no response-time commitments are made. The firehose
trigger currently cannot provide durable or lossless binary stream ingestion.
